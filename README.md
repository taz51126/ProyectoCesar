# Mi Control de Gastos (App Android)

Aplicación móvil para Android diseñada para gestionar tu salario e ingresos y llevar el control detallado de tus gastos (comidas, pasajes, colegiatura escolar, renta, gastos de hijos, agua, luz y conceptos personalizados), con presentación inicial y bloqueo mediante usuario y contraseña local.

## Cómo generar el `.apk` automáticamente en GitHub

1. Crea un repositorio nuevo en tu cuenta de [GitHub](https://github.com).
2. Sube **todos** los archivos y carpetas de este ZIP (asegúrate de incluir la carpeta oculta `.github/workflows/build-apk.yml`).
3. Ve a la pestaña **Actions** dentro de tu repositorio en GitHub.
4. Verás ejecutándose el flujo **Compilar APK Android** (tarda entre 2 y 4 minutos).
5. Cuando aparezca una palomita verde, entra al flujo y descarga el archivo **`Mi-Control-De-Gastos-APK`** en la sección **Artifacts**.
6. Descomprime el archivo descargado e instala `app-debug.apk` en tu teléfono Android.
